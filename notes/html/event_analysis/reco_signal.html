1. Processing one event

  1. Read the ion ADC vectors, SiPM ASIC vectors, channel positions and acquisition times.
  2. Estimate the ion baseline from samples taken before the induced current begins.
  3. Reconstruct ions in each collection bucket, using the calibrated linear or nonlinear CSA response.
  4. Correct the SiPM signal for saturation and recovery to obtain PE estimates at the original ASIC bucket duration.
  5. Add consecutive electron buckets to obtain the requested Z spacing.
  6. Return reconstructed-ion and PE vectors, together with reconstruction checks.

Reconstruction uses measured vectors, acquisition settings and calibration. Monte Carlo inputs are used separately for control plots.

  • Keep signed reconstructed values.
  • Keep all channels until zero suppression.
  • Ion and electron times share the event t0. Ion vectors use ms; electron vectors use μs.

2. Data types

Input vectors and timing

The input types are IonADCResponse and SiPMASICResponse. Their columns identify channels; their rows identify samples or time buckets.

IonReconstructionSettings

struct IonReconstructionSettings
    baseline_ms::Float32
    average_ms::Float32
    nonlinear_below_V::Float32
    max_iterations::Int64
    convergence_ions::Float32
end
  • baseline_ms: duration used to estimate the baseline before induced current.
  • average_ms: duration of each voltage average used in reconstruction.
  • nonlinear_below_V: measured-voltage threshold for selecting nonlinear reconstruction.
  • max_iterations: iteration limit for the reference fit used in validation.
  • convergence_ions: convergence threshold for that reference fit.

Proposed starting values: 10 ms baseline, 5 ms averages and the existing 0.63 V threshold. The reference fit uses at most 20 updates and a convergence threshold of 0.05 ions per bucket. The direct inverse uses neither setting. These settings are configurable in TOML.

IonReconstructionChecks

struct IonReconstructionChecks
    baseline_V::Vector{Float32}
    nonlinear::BitVector
    converged::BitVector
    adc_at_limit::BitVector
    voltage_residual_rms_V::Vector{Float32}
end

One entry per pad. adc_at_limit marks a pad with at least one endpoint ADC code. converged records successful reconstruction. The direct inverse leaves the voltage residual as NaN; voltage comparisons are calculated separately for validation.

ReconstructedIons

struct ReconstructedIons
    event_id::Int64
    channels::ReadoutChannels
    time::IonReadoutTime
    ions::Matrix{Float32}
    valid::BitMatrix
    checks::IonReconstructionChecks
end

Rows are collection buckets; columns are pads. valid records whether reconstruction produced a usable estimate. Failed estimates are NaN and excluded from energy sums with an explicit count.

ElectronReconstructionSettings

struct ElectronReconstructionSettings
    sipm::SiPM
    illuminated_microcells::Int64
    subtract_mean_dark::Bool
end

SiPM contains PDE, microcell count, gain, recovery time and dark rate. The illuminated microcell count comes from the optical geometry. Subtracting mean dark activity retains its fluctuations.

ReconstructedPE

struct ReconstructedPE
    event_id::Int64
    channels::ReadoutChannels
    time::ElectronReadoutTime
    acquired_end_us::Float32
    pe::Matrix{Float32}
    valid::BitMatrix
    asic_clipped::BitMatrix
end

Rows are time buckets; columns are SiPMs. PE estimates refer to detected photoelectrons before SiPM charge loss. They retain attachment loss; attachment correction belongs to the subsequent energy calculation. acquired_end_us preserves the end of the original acquisition when the final rebinned group is incomplete.

3. Ion reconstruction

From ADC counts to voltage

LSB_V = (maximum_V − minimum_V) / 2^bits
voltage_V = minimum_V + (ADC_count + 0.5) × LSB_V

This assigns the voltage at the centre of each ADC interval. The same calculation could be expressed in ADC counts; volts match the existing CSA calibration.

  1. Select baseline samples from the recorded acquisition interval, before the earliest induced current.
  2. Estimate the baseline and subtract its offset from the calibrated baseline.
  3. Form voltage averages of the requested duration. At 100 μs sampling, a 5 ms average contains 50 samples.
  4. Use the recorded collection-bucket start and duration to place each input-current response.

Baseline subtraction correlates the voltage estimates. Include this contribution, the measured CSA covariance and ADC quantisation in the reconstruction uncertainty.

Linear reconstruction

  1. Calculate the voltage produced by one collected ion in each output bucket, including the finite collection-current pulse.
  2. Apply the same averaging to those voltage vectors as to the measured ADC data.
  3. Solve for the ion counts whose summed responses reproduce the measured voltage averages.
  4. Calculate the reconstructed noise covariance using the same linear operation.
measured_voltage_drop = response_matrix × ions + noise

The response matrix includes contributions from neighbouring buckets and CSA recovery. Fit all buckets of a pad together. Weight the voltage averages with their covariance.

Nonlinear reconstruction

For voltage drop x below baseline, the calibrated CSA equation is:

dx/dt = g(x) × I(t)/e − r(x)
F(x) = integral of 1/g(x)

Q(t)/e = F(x(t)) − F(x(0)) + integral from 0 to t of r(x)/g(x)
  • g(x): gain in V per elementary charge.
  • r(x): recovery in V/s.
  • Q(t): cumulative induced charge.
  1. Select nonlinear reconstruction from the baseline-corrected voltage averages and configured threshold.
  2. Evaluate F at each ADC sample using the calibrated gain table.
  3. Integrate r/g between samples and add it to the change in F.
  4. Average the resulting cumulative charge over the configured 5 ms windows.
  5. Apply the prepared current-pulse inverse to obtain collected ions per bucket.

Prepare F and the current-pulse matrix once per event timing. The current-pulse matrix includes charge induced by neighbouring collection buckets and preserves the finite-path charge integral.

The nonlinear model is described in CSA voltage response. Signed estimates use the small-signal continuation above baseline. Values outside the positive voltage-drop calibration range are marked invalid.

Response matrix

  • Each column gives the sampled CSA voltage produced by one ion collected in a particular time bucket.
  • Apply the same voltage averaging used for the measured ADC vectors.
  • Use this matrix to reconstruct the ion counts and calculate their noise covariance.

Reuse the current and CSA calculations. Recompute the matrix for the configured sampling and bucket durations.

4. Electron reconstruction and rebinning

  1. Read ASIC charge in PE units at 250 ns per bucket.
  2. Apply the stationary mean SiPM correction at that bucket duration.
  3. Subtract mean dark activity when requested.
  4. Mark ASIC-clipped buckets as invalid for charge recovery.
  5. Add consecutive corrected buckets. A sum is valid only when all its contributing estimates are valid.

The existing axel_inverse gives a stationary mean correction:

estimated_PE = measured_PE / (1 − measured_PE × τ / (M × Δt))
  • τ is the microcell recovery time.
  • M is the number of illuminated microcells.
  • Δt is the original ASIC bucket duration.

Use the illuminated microcell count in this correction. Validate its mean bias with weak, steady and changing illumination, including dark activity across the full SiPM. The pilot controls show the tested range and measured bias.

  • Corrected PE versus expected detected PE, before and after rebinning.

Plots show entries, mean, standard deviation or RMS residual as appropriate. Comparisons use the same positive-input cells at each stage. Noise plots include zero-input channels.

Cleanup execution procedure

  1. Select the candidate groups and preserve their path/size/hash inventory.
  2. Check for active jobs and open files immediately before deletion; this audit does not certify that a later cleanup has no active writers.
  3. Extract the regression fixture and migrate duplicate-response references where required. Verify current viewer loading and report regeneration.
  4. Delete only the enumerated generated files, retaining acquired histories and all scientific source/provenance artifacts. Removing a directory merely because its name includes “pilot” would also remove current full production files.
  5. Measure free space again and record actual recovery and retained manifests.

The local detailed inventories and inspection scripts are under work/storage_audit/. The large-file inventory includes 3,081 files of at least 1,000,000 bytes; directory totals also include smaller files. The dedicated prepared-input inventory includes all selected PWL files regardless of size. This audit used size inventories, HDF5 headers, cards, source references and Git status. It did not perform a full bytewise deduplication of all acquired histories.

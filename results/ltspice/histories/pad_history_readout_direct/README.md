# Direct-collected pad histories through the optimized CSA

This run uses `config/pad_history_readout_direct.toml` and the corrected
`results/pixel_charge_1mm_direct/{bb0nu,electrons}.h5` and
`results/pixel_charge_1mm_4mm_direct/{bb0nu,electrons}.h5` input files.
Each contains 8000 events. The sources use direct sampled-carrier assignment,
with no intermediate diffusion-image cell centres in collection.

The circuit, finite-gap current, uniform intra-frame arrival assumption,
5 ms centred averaging, baseline and discharge correction are the same as in
the historical electronics study. Missing sparse cells remain zero buckets.
The source SHA256 identifiers and full collected-ion accounting are saved in
the four screen HDF5 files. `spice_inputs.h5` and the archived current files,
netlists and model copies reproduce the selected demanding histories.
`spice_analysis.h5` and `summary.h5` hold their reduced results and ADC assessment.

From the repository root:

```sh
python scripts/run_pad_history_pipeline.py \
  --config config/pad_history_readout_direct.toml --simulator /path/to/LTspice
```

`NAUSICAA_PAD_HISTORY_CARD` selects the same card for individual Julia stages.
The current CLI entry points default to the direct-input card. Historical
configuration and output directories remain preserved. A source snapshot under
`results/ltspice/pad_history_readout/source_snapshot/` records the earlier
wrappers and physical-screen implementation before configurable routing.

The corresponding nonlinear event study is
`results/ltspice/pad_compression_direct/8b0d8b859f56/`; its card is
`config/pad_history_viewer_direct.toml`. Numerical before/after comparisons are
in `results/ltspice/pad_history_direct_comparison/comparison.h5`, generated by
`scripts/electronics/histories/compare_inputs.jl`. The self-contained report
source is `latex_generated/pad_history_direct_comparison/report.tex`.

The report sources are generated without compiling their PDFs.

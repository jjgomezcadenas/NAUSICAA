# LTspice circuits and technical notes

| Directory | Contents |
|---|---|
| [reference/rogelio](reference/rogelio/) | Received circuits, models and reference results; the original README is in `initial/`. |
| [designs/variants](designs/variants/) | Circuit variants used by our design studies. |
| [releases](releases/) | Frozen collaborator packages and their original manifests. |
| [notes](notes/) | Authored CSA/current notes and Topmetal parameter discussion. |
| [papers](papers/) | Reference papers. |

Study cards live in `config/studies/electronics/`, results in `results/ltspice/`,
and generated PDFs in `latex_generated/ion_readout/`. The
[report catalogue](../latex_generated/index.html) links their documents.
See [runtime and organization](../docs/ltspice_setup.md) for installation,
regeneration and provenance. Recorded historical paths are resolved using
`docs/ltspice_paths.json`; frozen package contents remain unchanged.

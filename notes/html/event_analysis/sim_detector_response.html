02 · Detector response within the event frame

1. Processing one accepted event

  1. Read the MC hits, event position and frame returned by mc_fast_trigger. The frame contains the primary electrons and their delta-electron descendants, with a 20 mm margin on each side.
  2. Select the hits inside the frame. Record the deposited energy outside it.
  3. Calculate the number of electron–ion pairs produced by each selected hit, including Fano fluctuations.
  4. List every pad and SiPM covered by the frame. Calculate the ion and electron arrival intervals and their time buckets.
  5. Call sim_ion_detector_response to diffuse the ions and collect them into pad/time buckets.
  6. Call sim_electron_detector_response to apply attachment and diffusion, collect electrons into EL holes and calculate photons reaching the SiPMs.
  7. Return ion and photon vectors, channel positions, timing and the counts lost outside the frame.

Invisible deposits: an accepted event can contain a gamma depositing at most the veto threshold outside the frame. Those outside hits are ignored. Hits inside the frame remain included. The current threshold is 3 keV, configurable by TOML.

Connection to the following modules

  1. sim_ion_detector_response and sim_electron_detector_response: ion and photon vectors.
  2. sim_electronics_response: simulated CSA/ADC and SiPM/ASIC values, including noise on every channel in the frame.
  3. reco_signal: RI after linear or nonlinear CSA deconvolution; PE after the SiPM saturation and attachment corrections. Correct attachment by multiplying each PE bucket by exp(drift time / lifetime).
  4. reco_zero_suppression: select reconstructed channel vectors.
  5. write_event: save the selected vectors, frame, channels and timing.

Production processes each event in memory through detector response, electronics, signal reconstruction and zero suppression. Event vectors are written only after zero suppression. Signal reconstruction uses measured values and calibration parameters.

2. Frame, channels and time

Coordinates

  • Hits and the event frame use mc_vertex_frame.
  • Detector Z = hit Z + 10 × placement.ion_drift_cm.
  • Detector Z = 0 at ion collection; Z = chamber length at electron collection.
  • Intersect the acquisition frame with the detector Z limits.

Channel coverage

  • Use separate ion and EL grids, with pitch and transverse offset supplied by the card and recorded for the event.
  • Include every grid cell that overlaps the frame in XY. A cell touching only an outer edge adds no channel.
  • Keep the resulting rectangular channel list even when some channels receive zero counts.
  • Assign diffused positions to physical channels. Acquire each selected channel in full, including signal arriving beyond the original XY frame boundary.
  • Record signal reaching channels outside the acquired set, then discard it.

Time coverage

For detector-frame bounds Zmin and Zmax, chamber length L and the respective drift velocities:

Ion arrivals (ms):      [Z_min, Z_max] / ion_drift_velocity_mm_ms
Electron arrivals (μs): [L - Z_max, L - Z_min] / electron_drift_velocity_mm_us
  • Itrack and etrack share the same event t0. Every start time is an offset from that common reference.
  • Itrack times use milliseconds: start_ms and bucket_ms.
  • Etrack times use microseconds: start_us and bucket_us.
  • Convert units when comparing the two readouts. For example, start_ms = 1 and start_us = 1000 denote the same time after t0.
  • Round the start down and the end up to whole time buckets.
  • All channels of one readout use the same start time, bucket duration and number of buckets.
  • Time increases along the vectors. It corresponds to increasing Z for ions and decreasing Z for electrons.
  • Bucket duration and transverse pitch are independent parameters.
  • CSA baseline and filter-completion samples belong to the electronics acquisition settings.

Production script

  1. Select the accepted event's hits and acquisition frame.
  2. Call sample_fano_pairs.
  3. Call sim_ion_detector_response.
  4. Call sim_electron_detector_response with the same pair counts, event position and frame.
  5. Pass the vectors to electronics, signal reconstruction and zero suppression. Write the retained RI and PE channel vectors.

Use separate random-number generators for pair production, ion transport and electron response. Either response calculation can be repeated using the saved pair counts and event position.

The script reads TOML, constructs the settings and records the seeds.

5. Calculation and existing code

  • Ionisation: mean pairs = 1000 × EkeV/WeV; variance = F × mean. Use the existing integer sampler, including its small-count treatment.
  • Diffusion: sample physical positions and assign them directly to channels and time buckets. Use the existing event-distance prescription for the widths.
  • Attachment: electron survival probability = exp(−t/τ). The default lifetime is 30 ms, configurable by TOML. Use the event's electron drift time, as in the existing calculation. Ions receive no attachment loss.
  • EL: for N entering electrons, mean photons = N × Y; variance = N × J × Y.
  • Optical collection: sample photons reaching the SiPM using the analytical hole acceptance, TPB conversion and guide transmission. The current ELM output is blue photons.
  • Photon timing: use the parent electron arrival bucket.

Physics formulas and operating parameters: principle of operation and ELM note.

The operating note uses 300 V/cm at 15 bar. Its illustrative drift velocities are 0.15 mm/ms for ions and 0.6 mm/μs for electrons. The current card uses 3 mm TopMetal pitch and 20 ms buckets, spanning 3 mm in Z. SiPMs retain 4 mm pitch and 250 ns buckets, spanning 0.15 mm in Z. Event displays sum 20 electron buckets into 3 mm Z bins. Cards specify each drift velocity and bucket duration used in each calculation.

6. Tests

Channel coverageA small frame at a grid edge selects the expected cells, including channels with zero counts.
Common time referenceIon times in ms and electron times in μs refer to the same t0. Unit conversion preserves their relative arrival times.

Bucket edgesAssign a count on an internal edge to the next bucket; include the final frame edge in the last bucket.
No diffusionKnown hit positions give the expected channels and times.
Diffusion at the frame edgeRetain signal on both sides of the XY frame boundary when it reaches a channel in the frame. Record and discard signal reaching a channel outside the frame.
Charge and photon totalsCollected ions + excluded ions = initial pairs. Collected photons + uncollected photons = emitted photons.
FluctuationsRecover the expected Fano, attachment, EL and optical means and variances over repeated events.

StorageBound vector memory by channels × buckets. Check saved control totals and histograms. Set the control-file budget from its columns and example projections.

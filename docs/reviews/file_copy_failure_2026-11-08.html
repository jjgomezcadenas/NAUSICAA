File-copy failure: confirmed cause and guards

8 November 2026

Cause

Julia 1.12.6 truncates the transferred byte count to a signed 32-bit integer in its sendfile path. The copy loop repeats when this count becomes zero. A bounded two-call experiment confirmed the failure without running the unbounded loop.

The 341.7 GB failed temporary was removed after verifying the completed source. Our missing size guard and failure cleanup allowed the runtime failure to exhaust the disk.

Protections

  • Bounded 8 MiB reads/writes; exact copy length and SHA-256.
  • At most 10% growth for publication metadata, checked after each flushed update.
  • Disk-space checks and a 1 GiB reserve.
  • Unique temporary, cleanup on failure and atomic publication.

Verified on the production output

The guarded publication completed all 8,000 events and 897,306,359 ions. The 8,793,451,765-byte source became 8,793,456,974 bytes: only 5,209 additional metadata bytes. No numerical rerun was needed. Guard and CSA tests, 73 Python tests and physics checks passed.

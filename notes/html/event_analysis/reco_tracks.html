Track reconstruction

Processing saved hits

  1. Read itrack and etrack hits for an MC event.
  2. Build the existing kNN graphs from all retained hits.
  3. Build Petit’s minimum spanning tree for each component. Walk the tree twice, counting edges, to find its endpoints.
  4. Save component membership and ordered backbone positions separately from the hit file.

Settings

  • Itrack: k = 10; maximum connection distance = 7.5σₜ.
  • Etrack: k = 20; maximum connection distance = 6σₜ.
  • Each track uses its event's transverse diffusion width. Both settings are configurable by TOML.
  • The viewer selects itrack hits above 5 keV and etrack hits above 1 keV. Event energy uses the signed charge before these cuts.

Existing calculations

  • make_tracks: neighbours and connected components.
  • find_extremes_mst_diameter: Petit’s tree, endpoints and connecting path.
  • energy_in_spheres_around_extremes: energies within endpoint spheres, using all component hits.
  • get_raw_path: coordinates and distances along the backbone.

These functions are in src/event_analysis/. scripts/production/prepare_hit_presentation.jl reads the compact hit file and saves projections and backbones. An optional graph card and output directory select another kNN configuration without changing the hit file.

Endpoint spheres

  • Show spheres around the two endpoints of the component containing the most hits.
  • Compare radii 2σₜ and 3σₜ. Select the radius in the viewer.
  • E₁ is the larger sphere energy; E₂ is the smaller. Record the energy shared by both spheres.
  • Draw circles in the projections and spheres in 3D. The connecting paths can be hidden.

Petit ion reconstruction

  1. Convert deposited energy to carrier counts and sample Gaussian diffusion.
  2. Keep occupied diffusion cells, then voxelise them.
  3. Apply an energy threshold and build the graph.

The reconstruction in itaca_track_reco_mt.jl and itaca_single_track_analysis.jl adds no CSA or ADC noise. Empty cells do not acquire noise hits. The default ion threshold is 10 ions, equivalent to 0.25 keV with Petit’s 40 ions/keV conversion. Our reconstructed ion hits include CSA noise after deconvolution.

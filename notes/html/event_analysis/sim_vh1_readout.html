1. Scope

VH1 is the reset two-capacitor charge-sensitive amplifier of NAUSICAA v2 (Sections 7, 13 and 14), simulated as an alternative to the present CSA/ADC chain of electronics response. It takes the same ion vectors from detector response and returns the same ReconstructedIons as signal reconstruction, so hits, energies and tracks follow unchanged. The electron arm is not involved.

The module src/vh1/VH1Readout.jl is independent: it uses the current builder, noise sampler, ADC quantiser, averaged covariance and output types of the existing modules and modifies none of them.

Circuit model: no discharge element; the output is v_ref_V minus gain_V_per_ion times the ions accumulated since the reset; linear while the output stays inside output_window_V. Converter: conversions_per_frame integrations per 20 ms frame, each the mean of the output over the last conversion_window_ms of its sub-interval, quantised to 16 bits. Defaults: two contiguous 10 ms integrations per frame. Noise after reconstruction: 31 ions per bucket with 3 fF and about 33 with the production capacitors; the present chain gives 50 on the same footing.

Production cards: vh1_device_changes_cf30f.toml for 4 mm pitch (30 fF, range 92 300 ions) and vh1_device_changes_cf20f.toml for 3 mm pitch (20 fF, range 61 900 ions). The 3 fF card holds 10 370 ions per pad and saturates 1.5 % of the pads of a bb0nu event at 4 mm pitch; the 100-event pilots with the production cards saturated none, with mean signal-to-noise per pad-bucket 10.1 at 4 mm and 6.8 at 3 mm. See the pilot comparison linked from the index. vh1_device_changes_cf20f_15ms.toml is the 20 fF card with 15 ms frames (two 7.5 ms conversions) for the ion drift velocity of 20.0 cm/s (iItaca II_L1000_D500), the same circuit, gain and noise spectrum; the gain and the window are AC results and the noise is a stationary spectrum, so the shorter frame needs no new SPICE run. On the same 130 pilot events it gives 33.1 ions of noise per pad-bucket against 32.6 with 20 ms frames, with the same saturation, residuals, energy and hits (frame comparison; make vh1-frame-comparison). A run resolves only if the VH1 frame equals the detector's ion bucket.

2. Processing one accepted event

Electronics (sim_vh1_electronics)

  1. Read the ion vectors: counts per collection bucket and pad, bucket timing, channel positions.
  2. Place the frames: one reference frame ending where the earliest induced current of the first bucket begins, then 20 ms frames until the end of the last bucket.
  3. Build the internal 100 µs grid over the frames and the pad current from the single-ion pulse, uniform arrival within each bucket, and the counts (same current builder as the present chain).
  4. Integrate the current to the cumulative charge and form the noiseless readings: for each reading window, the mean of v_ref_V − gain × charge at the cell midpoints. Empty pads read v_ref_V.
  5. Flag the pad as saturated if any noiseless reading lies outside the output window.
  6. Draw one noise vector per pad on the internal grid from the VH1 spectrum, average it over the same windows, add it to the readings.
  7. Quantise each reading with the 16-bit converter; count codes outside the range. Return the code matrix, readings by pads.

Reconstruction (prepare_vh1_reconstruction, reco_vh1_ions)

  1. Build the response matrix once per bucket count: for one ion in each bucket, the readings formed exactly as in step 4, expressed as drops below the reference reading (the last reading of the reference frame).
  2. Build the covariance of reference-minus-reading from the VH1 noise covariance on the internal grid, averaged over the windows, plus converter quantisation.
  3. Whiten with the Cholesky factor, solve by QR; keep the inverse and the predicted ion covariance.
  4. Per pad: codes to volts, drops below the reference, counts = inverse × drops, residual RMS. Pads saturated or with a code at either end of the range are invalid (NaN).
  5. Return ReconstructedIons with the existing checks (baseline = reference reading, nonlinear = false).

5. Noise model

The source is the one-sided output noise spectral density of the VH1 circuit from LTspice (results/ltspice/design/VH1/improvements/noise_combined_W4_23u.csv, 0.1 mHz to 1 MHz). voltage_noise_from_spectrum of the present chain turns it into the covariance of samples 100 µs apart: the spectrum is integrated analytically between its knots, each piece of power is assigned to the FFT frequency bin it falls in, frequencies above the Nyquist frequency of the 100 µs grid are folded onto their alias, and the inverse FFT of the binned power is the covariance. One Gaussian vector per pad with that covariance is drawn by sample_csa_noise! (circulant embedding, inverse FFT of independent complex Gaussians). The readings then average the vector over the same windows as the signal, so the noise of a reading is exactly the window average of the output noise. Quantisation adds LSB²/12 per reading in the covariance (27 µV steps, negligible).

Pads are independent. Reset noise, switch charge injection and clock feedthrough are not modelled.

6. Reconstruction and its conditioning

Readings are drops below the reference reading; the model is drops = response × counts + noise with the response built from a single ion per bucket by the identical window operation, so noiseless inputs are recovered exactly. The solve is the generalised least squares of the present chain. Because the output ramps while the ions of a bucket arrive, a reading that integrates a whole frame sees only part of its own bucket and part of the next; one reading per frame therefore gives a poorly conditioned matrix and amplified noise. Two readings per frame resolve where in the frame the charge arrived. Per-bucket noise for the default circuit and 20 ms buckets, from the prepared covariance and confirmed on noise-only pads:

8. Tests

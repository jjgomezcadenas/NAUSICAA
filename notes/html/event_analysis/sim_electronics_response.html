1. Processing one accepted event

  1. Read the ion and photon vectors, channels in the frame and arrival times from detector response.
  2. Extend the ion acquisition interval by the configured baseline and final sampling intervals.
  3. For pads with signal, calculate induced current and CSA voltage. For empty pads, use the baseline voltage. Add voltage noise and digitise every pad.
  4. For each SiPM, sample photodetection and dark activity, calculate avalanche charge with occupancy and recovery, and apply the ASIC response.
  5. Return ADC-count vectors for ions and PE-equivalent response vectors for electrons. Keep every channel in the frame.
  6. Pass these vectors to signal reconstruction. Save control statistics and selected examples.

2. Data types

Inputs from detector response

  • IonDetectorResponse: event number, frame, placement and ion vectors.
  • ElectronDetectorResponse: event number, frame, placement and photon vectors.
  • ReadoutChannels: channel indices and positions.
  • IonReadoutTime and ElectronReadoutTime: bucket start, duration and count.

All matrices below have time along rows and channels along columns. Both readouts retain the common event t0.

NonlinearCSA

struct NonlinearCSA
    knots_V::Vector{Float64}
    gain_V_per_e::Vector{Float64}
    recovery_V_s::Vector{Float64}
    baseline_V::Float64
    step_s::Float64
end
  • knots_V: voltage drops below baseline at which the calibration is tabulated.
  • gain_V_per_e: voltage change per input elementary charge at each voltage drop.
  • recovery_V_s: rate at which the voltage returns towards baseline.
  • baseline_V: output voltage before the signal.
  • step_s: maximum integration step.

For voltage drop x below baseline:

x = baseline_V − output_V

dx/dt = gain(x) × current(t) / e − recovery(x)
output_V = baseline_V − x

Here e is the elementary charge. Gain and recovery are interpolated between the tabulated values. Integrating this equation gives the output voltage as charge arrives and the CSA recovers.

Calibration

  1. Use SPICE calculations with known input current and output voltage versus time.
  2. Fit the gain and recovery values so that the equation reproduces the voltage changes. Require positive gain, nonnegative recovery and zero recovery at baseline.
  3. Check complete voltage vectors using separate events that were not used in the fit.

Valid voltage range

  • The calibrated voltage drop runs from zero to the last value in knots_V. The corresponding output voltage runs from baseline_V − knots_V[end] to baseline_V.
  • Stop and report a pad whose voltage exceeds this range.
  • The calibration applies to the circuit and input-current prescription used in the fit. Changes to either require validation.

CSAVoltageNoise

struct CSAVoltageNoise
    sample_us::Float32
    covariance_V2::Vector{Float64}
end
  • Element k gives the voltage covariance at lag (k - 1) × sample_us.
  • The first element is the voltage variance.
  • Reuse the saved CSA voltage-noise spectrum and its frequency range. Calculate covariance at the selected ADC sampling interval, including aliasing of frequencies above Nyquist.

The covariance vector covers a complete symmetric FFT period. Prepare a shorter period that preserves every time lag used by the event and has a nonnegative spectrum. Reuse its factors, FFT plan and working arrays across pads. Each pad receives independent random numbers.

SiPM

struct SiPM
    pde::Float64
    microcells::Int
    gain::Float64
    recovery_s::Float64
    dark_rate_Hz::Float64
end
  • pde: probability that a photon arriving at the SiPM produces a primary avalanche.
  • microcells: total number of microcells in the SiPM.
  • gain: number of electrons released by a fully recovered microcell. Its avalanche charge is q₀ = e × gain.
  • recovery_s: exponential microcell recovery time, in seconds.
  • dark_rate_Hz: mean number of primary dark avalanches per second for the whole SiPM.

Photodetection and recovery

  1. For N photons in a bucket, sample the number of detected photons from Binomial(N, PDE).
  2. Sample primary dark avalanches from Poisson(dark_rate_Hz × bucket duration).
  3. Distribute optical avalanches over the illuminated microcells and dark avalanches over the whole SiPM.
  4. A fully recovered cell releases q₀. A partially recovered cell releases r × q₀, where r is its recovered fraction. Firing resets that cell's recovered fraction to zero.
  5. Between avalanches, update recovery over elapsed time Δt using the equation below. Carry recovery from one bucket to the next.
r_after = 1 − (1 − r_before) × exp(−Δt / recovery_s)

Before the first bucket, initialise recovery for steady dark activity. With zero dark rate, all cells start fully recovered. PDE is fixed in this model; recovery changes avalanche charge.

SiPMStatisticalOptions

struct SiPMStatisticalOptions
    substeps::Int
    sparse_trigger_limit::Int
    initial_state::Symbol
end
  • substeps: divide buckets with more than 16 avalanches into 64 intervals of 3.91 ns each. The constructor default is 64.
  • sparse_trigger_limit: with 16 or fewer optical plus dark avalanches, simulate their individual arrival times. The constructor default is 16, a computational choice. This setting selects the calculation method; it discards no signal.
  • initial_state: :fully_recovered sets R = S = M. Historical cards can select :stationary_dark.

Statistical calculation

  • Keep two sums for the microcells: R = sum(r) and S = sum(r²). They describe the mean recovery and its spread.
  • Start fully recovered: R = S = M, with no initial random draws. Simulate dark avalanches and recovery from the first bucket.
  • At or below sparse_trigger_limit, sample individual avalanche times uniformly within the bucket. Calculate each released charge from the recovery sums.
  • Above that limit, distribute the avalanches among substeps equal intervals. Calculate their combined charge at each interval's midpoint, including cells reached more than once.
  • For each calculation, sample bounded charge with the mean and variance obtained from microcell occupancy and recovery. Update R and S after releasing the charge.
  • The statistical model approximates the full charge distribution. Check its charge mean and variance against the individual-microcell simulation, and check convergence with increasing substeps.

These parameters control numerical accuracy. They do not change the saved bucket duration.

SiPmAsic

struct SiPmAsic
    bucket_width_s::Float64
    noise_rms_pe::Float64
    current_limit_A::Float64
end
  • bucket_width_s: ASIC integration time per bucket, in seconds.
  • noise_rms_pe: standard deviation of independent Gaussian ASIC noise per bucket, expressed in fully recovered avalanche units.
  • current_limit_A: maximum average current represented by the ASIC.

ASIC response

For SiPM charge Q in a bucket of duration Δt:

noise_PE ~ Normal(0, noise_rms_pe²)
input_PE = Q / q₀ + noise_PE
limit_PE = current_limit_A × Δt / q₀
output_PE = min(input_PE, limit_PE)

Mark buckets with input_PE above limit_PE as clipped. Retain negative noise values. The output is measured avalanche charge expressed in PE units.

4. Settings and calculation

Ions

  • ADC: 100 μs sampling, 12 bits and provisional range 0–1.8 V.
  • Store ADC codes as UInt16. Require 1–16 bits.
  • Code width: ΔV = (maximum_V − minimum_V) / 2bits.
  • Code = floor((V − minimum_V) / ΔV), limited to 0…2bits − 1.
  • Default CSA mode: hybrid nonlinear, with the existing 0.63 V threshold.
  • The pilot card sets baseline_ms = 10, signal_tail_ms = 5 and input_noise_rms_V = 0. Quantisation remains included.
  • Reuse the existing linear calibration, nonlinear tables and CSA noise spectrum. Validate their application to 100 μs voltage samples against saved SPICE vectors and direct covariance integration.

SiPM and ASIC

  • Keep the selected SiPM and ASIC parameters from the production card.
  • Use 250 ns photon and ASIC buckets.
  • Sample PDE once. Apply microcell occupancy, recovery and dark activity before ASIC noise and clipping.
  • ASIC limit in PE = current_limit_A × bucket_width_s / (elementary_charge_C × gain).
  • The electronics stage keeps the 250 ns vectors. After signal reconstruction, sum 20 buckets to obtain the 3 mm Z interval.

Reused calculations

  • Current: the existing finite-gap weighting potential, with uniform ion collection times within each bucket.
  • Linear voltage: the existing calibrated decay time and small-signal SPICE response, expressed as an impulse response for ADC sampling.
  • Nonlinear voltage: the existing voltage-dependent gain and recovery tables.
  • Noise: the existing one-sided CSA spectrum and covariance integration.
  • SiPM and ASIC: the existing statistical occupancy/recovery and bucket-integrating response functions.

5. Efficient CSA simulation

Prepare once per run

  1. Read the ion electronics card and verify the circuit and calibration files.
  2. Load the linear gain, decay time, baseline voltage and nonlinear gain/recovery tables.
  3. Prepare the single-ion current pulse and its integral. For each ion bucket duration, prepare the current produced by uniform collection within one bucket.
  4. Load the CSA voltage-noise spectrum and ADC settings.

Reuse calculations and arrays

  • Events with the same number of ADC samples can share the prepared noise calculation.
  • A preparation for a longer event can also serve a shorter event.
  • Reuse the arrays that hold temporary voltages and ADC values.
  • Prepare new calculations only when the event needs more samples or the electronics settings change.
  • Keep at most 64 MiB of event-length tables and 64 MiB of prepared noise arrays. Release cached entries when a new entry would exceed the limit. ADC output remains limited to 256 MiB per event.

Each pad still receives its own independent random noise.

Calculate each pad

  1. For an empty pad, use the baseline voltage.
  2. For a pad with signal, build its current from the prepared bucket-current response. Record its peak current during this calculation.
  3. Calculate the linear voltage. If it falls below the configured threshold, calculate the voltage with the existing nonlinear model.
  4. Add an independent noise vector for the pad, retaining correlations between its time samples.
  5. Digitise and return the ADC-count vector.

CSA voltage response

Before ions arrive, the CSA output is at its baseline voltage. Input current lowers the output voltage; feedback discharges the accumulated charge and brings the output back towards baseline. The voltage at a given time therefore depends on the current arriving then and on charge accumulated earlier.

  • Linear response: a given input charge produces the same voltage change at any starting voltage. Gain and decay time are constant, and responses to separate charge arrivals add.
  • Nonlinear response: as the output moves away from baseline, the transistor operating conditions change. The voltage change per additional charge and the rate of recovery depend on the current output voltage.

Linear voltage from an exponential response

The current linear model has response −G × exp(−t/τ) to a unit input charge. G is the positive gain in V/C and τ is the decay time in seconds. For voltage drop x below baseline:

dx/dt = G × I(t) − x/τ
output_V = baseline_V − x

Between two current points separated by h seconds, the current is a straight line:

I(t) = I₀ + b × t       for 0 ≤ t ≤ h
b = (I₁ − I₀) / h

a = exp(−h/τ)
x₁ = a × x₀ + G × [I₀ × τ × (1 − a)
                    + b × (τ × h − τ² × (1 − a))]
  • I₀ and I₁ are the current at the interval ends, in amperes.
  • x₀ and x₁ are the voltage drops at those ends, in volts.
  • Advance through the current points and ADC sample times in order. Split an interval at an ADC sample when needed.
  • This update is exact for the supplied straight current segments and exponential response.
  • For very short intervals, evaluate the exponential differences using stable small-interval expressions.

Use G and τ from the existing calibration and check that they reproduce the tabulated linear response. The recurrence returns the requested 100 μs samples directly.

Nonlinear voltage

The model uses the voltage drop x = baseline_V − output_V to describe how far the CSA has moved from its initial state. Two tables specify its response at that voltage:

  • Gain: the additional voltage drop produced by one elementary input charge, in V/e.
  • Recovery: the rate at which the voltage drop decreases through feedback, in V/s.

The three arrays in NonlinearCSA form the rows of this table:

Voltage drop (V)
knots_V		Gain (V/e)
gain_V_per_e		Recovery (V/s)
recovery_V_s
0g₀0
x₁g₁r₁
x₂g₂r₂
………

The values are fitted from SPICE current and voltage vectors. At a voltage drop between two rows, interpolate both gain and recovery between those rows.

For current I(t), the voltage evolves as:

dx/dt = gain(x) × I(t) / e − recovery(x)
output_V = baseline_V − x
  • I(t)/e is the number of elementary input charges per second. Multiplying by gain(x) gives the rate of voltage drop caused by arriving charge.
  • Recovery(x) gives the opposing rate from feedback discharge. When the input current is zero, this term determines the return towards baseline.
  • If gain decreases as x grows, the same additional charge produces a smaller voltage change. If recovery increases, more charge is discharged while ions are arriving. Both effects are represented by the fitted tables.
  • Two identical current pulses can therefore produce different voltage changes if the second arrives before the CSA has recovered from the first.

The linear model is the special case gain(x) = e × G and recovery(x) = x/τ. The nonlinear tables allow both relationships to vary with voltage.

Calculation

  1. Load the tables once per run.
  2. Use the same pad current calculated for the linear model.
  3. If the predicted linear voltage falls below the configured threshold, calculate the nonlinear response from the start of that pad's current.
  4. Start at x = 0. At each integration step, obtain gain and recovery from the tables at the current x.
  5. Advance with the existing fourth-order Runge–Kutta method. End each step at the next current point, ADC sample or configured maximum step, whichever comes first.
  6. Return voltage at the ADC sample times.

The current 0.63 V threshold selects which calculation is used. The tabulated gain and recovery vary continuously between their calibration points.

Reuse and checks

  • Share the calibration tables across pads and events.
  • Reuse working arrays, starting each pad at its own baseline.
  • Record peak-current exceedances. Stop if voltage leaves the tabulated range.

The exponential recurrence applies to the linear model. The nonlinear equation and integration method remain unchanged.

Convolution comparison

  • Keep the current convolution as a reference during validation.
  • Prepare its common response transform once per sampling configuration and vector length, and reuse the FFT plans and arrays across pads.
  • Compare the recurrence with the convolution at its current 25 μs internal spacing and at finer spacing.
  • For a future linear response that is not exponential, use the prepared convolution.

Charge Sensitive Amplifier (CSA) Design Equations & Analytical Models

X-FAB 180nm CMOS Process Formulation (Vdda = 1.8V, Folded Cascode Single-Ended Core)

1. Charge Sensitivity & Closed-Loop Transfer Function

An ideal Charge Sensitive Amplifier converts an injected charge Qin at the input detector node into a proportional voltage step at the output:

Vout,ideal = - Qin / Cf

Taking into account the finite open-loop amplifier gain Av0 and total input capacitance Cin,tot = Cd1 + Cgs1 + Cgd1 + Cf(1 + Av0), the charge collection efficiency ηQ is derived as:

ηQ = [ Av0 · Cf ] / [ Av0 · Cf + Cd1 + Cin,par ] = 1 / [ 1 + (Cd1 + Cin,par) / (Av0 · Cf) ]

Peak output pulse amplitude: Vout,peak = - (Qin / Cf) · ηQ.

2. Small-Signal Open-Loop Gain & Output Impedance

Transconductance of the primary PMOS input transistor M1:

gm1 = √( 2 · µp · Cox · (W/L)1 · ID1 )

Output impedance at node 'out' formed by the parallel combination of the NMOS cascode branch (M4-M3) and PMOS cascode branch (M5-M6):

Rout = Rdn || Rup = [ gm4 · ro4 · ro3 ] || [ gm5 · ro5 · ro6 ]

Low-frequency DC Open-Loop Voltage Gain:

Av0 = gm1 · Rout = gm1 · ( [ gm4 ro4 ro3 ] || [ gm5 ro5 ro6 ] )

3. Feedback MOSFET Reset Resistance Modeling (Mf)

Feedback MOSFET Mf operating in deep linear / triode region or subthreshold provides continuous discharge time constant τf = Rf · Cf:

Rf ≈ 1 / [ µn · Cox · (W/L)f · (Vdis - Vin,DC - Vthn) ] (Triode Region)
Rf,subth ≈ (n · UT) / [ Isub0 · exp( (Vdis - Vin,DC - Vthn) / (n · UT) ) ] (Subthreshold Region)

4. Equivalent Noise Charge (ENC) Formulations

The input-referred noise spectral density includes thermal noise from M1, load transistors, and 1/f flicker noise:

Sv(f) = (8/3) · (k · T / gm1) · (1 + (gm2 + gm3)/gm1) + [ Kf / (Cox · W1 · L1 · f) ]

For a standard CR-RC pulse shaper with shaping time τs, the integrated Equivalent Noise Charge (ENC) in rms electrons is:

ENCthermal = [ Ctot / q ] · √( (2/3) · (k · T / gm1) / τs )
ENCflicker = [ Ctot / q ] · √( (Kf / (Cox · W1 · L1)) · A2 )
ENCfeedback = [ Ctot / q ] · √( (2 · k · T · τs) / Rf )
ENCtotal = √( ENCthermal2 + ENCflicker2 + ENCfeedback2 ) [e⁻ rms]

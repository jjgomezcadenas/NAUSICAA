Extend the nonlinear CSA calibration

Cover the rare pad vectors with currents or voltage excursions beyond the existing calibration, while keeping production free of SPICE runs.

  1. Scan the full ion sample for peak current, accumulated charge and closely spaced pulses.
  2. Select representative extreme pad vectors.
  3. Compare the existing nonlinear model with SPICE in a separate calibration study.
  4. Extend the gain and recovery tables where needed. Change the model only if these comparisons show that voltage-dependent gain and recovery are insufficient.
  5. Validate on separate events using the agreed 0.5 ENC accuracy criterion.

Current production rule

  • Use the existing linear and nonlinear models.
  • Record peak-current exceedances, including event number, pad and current relative to the calibration maximum.
  • A peak-current exceedance alone does not reject the event.
  • Stop and report if the nonlinear voltage leaves its tabulated range.
  • Do not launch SPICE automatically.

# VH1 improvements: device sweeps

Generated by `scripts/electronics/design/vh1_improvements.py`; results in
`results/ltspice/design/VH1/improvements/` (`summary.md`, `summary.json`,
noise spectra as CSV). The circuit is the VH1 prototype of the parent
directory; only the listed device sizes change.

Every variant is re-tuned with the reset loop closed (output = gate + 0.885 V):
`Vnload` (gate of M3) for the M1 current of 210.3 uA and `Vnmos` (gate of M2)
for an output level of 0.886 V. The cascode bias `Vncasc` is not re-tuned,
which limits how long M3 can be made: at 8 and 16 um M3 needs more drain
voltage than the 0.18 V at node `med` and leaves saturation.

| Sweep | Values | Purpose |
|---|---|---|
| M2 length | 0.5 (base), 1, 2, 4 um | Lower transconductance of the current source feeding M1, the largest noise term |
| M3 length | 2 (base), 4, 8, 16 um | Same for the load transistor |
| M4 width | 2.88 (base), 5.76, 11.5, 23, 46 um | Cascode impedance at `med`; effect on input capacitance and open-loop gain |
| M1 width | 220 (base), 110, 55 um | Input capacitance against transconductance of the input device |

`combined` takes the best feasible value of each sweep that beats the base
ENC by more than 2 %; `combined_W4_23u` adds the 23 um cascode, which
restores the open-loop gain lost with the longer M3.

`swap_practical_reset.cir` replaces the ideal reset level shift by a
resistor of 8.85 Mohm and a 0.1 uA current sink, a current the 0.38 uA
output stage can supply.

Decks in this directory are the AC and noise decks of each variant with its
tuned biases; the operating-point decks used for tuning are not kept.

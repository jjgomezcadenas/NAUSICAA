Readout implementation plan

Event processing

  1. MC fast trigger: place the event, apply the selection and define the acquisition frame.
  2. Detector response: calculate ion vectors and photons reaching the SiPMs.
  3. Electronics response: calculate CSA/ADC and SiPM/ASIC values.
  4. Signal reconstruction: obtain signed ion and PE vectors.
  5. Event energy and hit output: calculate event totals before cuts, rebin electrons, retain hits above the configured cut and save totals and hits.
  6. Track reconstruction: read the hits and calculate kNN graphs and backbones.
  7. Presentation: read saved results to generate distributions and the event viewer.

Steps 1–5 process one event in memory. Steps 6–7 reuse the saved output.

Configuration

  • For each energy deposit, calculate electron–ion pairs including Fano fluctuations. The ion and electron calculations use the same pair counts and event position.
  • Ion and electron drift distances are complementary.
  • TOML cards specify the detector, electronics, reconstruction, hit cuts and graph settings.
  • Run labels include the ion and EL pitches. Save cards, seeds, source checksums and code identifiers.

Output

  • The agreed production output is one compressed HDF5 file containing event totals and retained itrack/etrack hits.
  • Save four Float32 hit columns: X, Y, Z in mm and energy in keV. Event offsets identify each event.
  • Event energies use all signed reconstructed charge before hit cuts. The minimum hit cut is 1 keV.
  • Expected hit size: approximately 40 MiB per 1,000 events before compression.
  • Write graph results separately; do not duplicate detector or electronics vectors.
  • Production creates no diagnostic histograms. Debug calculations require explicit selection and an event limit.
